# insurance-data-analysis

##This project explore factors that will effect the total claim amount of the insurance, using Pandas, data Visualization, adn Meanchine Learning.

##Tools used
-Python
-Pandas
-Matplotlib
-Scikit-learn
-SQL

## Models
-Linear Regression
-Knn Regression

##Key Findings
-The income, Employment status and the Vehicle Class are important factors of the total claim amount
-Linear Regression model have a higher R2 than the KNN Regression model
